2) CPU มี 2 ส่วนหลัก

🧮
ALUหน่วยคำนวณและตรรกะ · บวก ลบ เปรียบเทียบ มาก/น้อย
🚦
CUหน่วยควบคุม · "ตำรวจจราจร" สั่งว่าใครทำอะไรก่อนหลัง

🌳 ชั้นต้นไม้ใหญ่ · เจาะลึก

คำศัพท์ความหมายเทียบมือถือ
GHz (กิกะเฮิรตซ์)ความเร็วสัญญาณนาฬิกาของ CPU · ตัวเลขมาก = จังหวะทำงานถี่สเปก "2.8 GHz"
Core (แกน)จำนวนสมองย่อยใน CPU ทำงานพร้อมกันได้"Octa-core" = 8 แกน
Cacheหน่วยความจำเล็กมาก เร็วมาก อยู่ติด CPU เก็บของที่ใช้บ่อยกระเป๋าเสื้อ หยิบไวกว่าโต๊ะ
GPUหน่วยประมวลผลกราฟิก ช่วยงานภาพ วิดีโอ เกมเล่นเกมภาพสวยลื่น
Mainboardแผงวงจรหลัก เชื่อมทุกชิ้นส่วนเข้าด้วยกันแผ่นวงจรในเครื่อง
HDD vs SSDHDD มีจานหมุน ราคาถูก ช้ากว่า · SSD ใช้ชิป ไม่มีชิ้นส่วนเคลื่อนไหว เร็วกว่ามือถือใช้หน่วยเก็บแบบชิป
Firmware / BIOSโปรแกรมเล็กที่ฝังใน ROM ใช้ปลุกเครื่องตอนเปิดหน้าจอโลโก้ตอนเปิดเครื่อง
📝 ลำดับความเร็วหน่วยความจำ (เร็ว → ช้า): Register ใน CPU → Cache → RAM → SSD → HDD
ยิ่งเร็ว ยิ่งแพง ยิ่งจุน้อย
🖨️ ศัพท์จอ/เครื่องพิมพ์: Pixel = จุดเล็กที่สุดบนจอ · Resolution = จำนวนจุด เช่น 1920×1080 · dpi = จุดต่อนิ้ว ใช้วัดความละเอียดงานพิมพ์/สแกน

🧩 ซอฟต์แวร์ คืออะไร?

🌱 ชั้นเมล็ด · รู้แค่นี้ก็เข้าใจ

ซอฟต์แวร์ = ชุดคำสั่ง ที่บอกเครื่องว่าต้องทำอะไร · จับต้องไม่ได้ ✋❌ ต่างจากฮาร์ดแวร์ที่จับได้ · เริ่มจากหน้าจอแรกที่เห็นทุกวันตอนปลดล็อกมือถือ

1 👀 หน้าจอหลักของมือถือ

แตะวงกลมตัวเลข (หรือแตะไอคอน) ดูว่าอะไรเป็น แอป อะไรเป็นของ ระบบ 👆

👆 แตะวงกลมตัวเลข ดูว่าแต่ละอย่างคือซอฟต์แวร์แบบไหน
👀 สังเกตไหม: ไอคอนแต่ละอัน = แอป 1 ตัว ทำงานคนละเรื่อง · แต่ เวลา แบต ปุ่มย้อนกลับ หน้าตั้งค่า ไม่ได้เป็นของแอปไหน — เป็นของ "ระบบปฏิบัติการ" ที่คุมทั้งเครื่อง
2 🔧 เปิดดูข้างใน: ถ่ายรูป 1 ครั้ง ผ่านอะไรบ้าง

ในเครื่องซ้อนกันเป็น ชั้น ๆ เหมือนเค้ก 🎂 · กดปุ่มด้านล่างทีละครั้ง ดูคำสั่ง "ถ่ายรูป" วิ่งลงไปแล้ววิ่งกลับขึ้นมา 👇

👤เรา (ผู้ใช้)คนแตะหน้าจอ

⚙️ระบบปฏิบัติการ (Android / iOS)ซอฟต์แวร์ระบบ · ผู้จัดการคุมทั้งเครื่อง

1) โปรแกรมร้าย (Malware) แต่ละแบบ

ชื่อลักษณะเปรียบเทียบ
🦠 ไวรัส (Virus)แฝงไปกับไฟล์/โปรแกรม · ทำงานเมื่อมีคนเปิดไฟล์นั้นเชื้อโรคติดมากับของ
🪱 เวิร์ม (Worm)แพร่ตัวเองผ่านเครือข่ายได้เอง ไม่ต้องรอคนเปิดหนอนคลานไปเครื่องอื่นเอง
🐴 ม้าโทรจัน (Trojan)ปลอมเป็นโปรแกรมดี แต่แอบทำร้ายข้างในม้าไม้ที่มีทหารซ่อน
🔒 แรนซัมแวร์ (Ransomware)ล็อกไฟล์ในเครื่อง แล้วเรียกค่าไถ่จับไฟล์เป็นตัวประกัน
👀 สปายแวร์ (Spyware)แอบเก็บข้อมูล/รหัสผ่านส่งให้คนร้ายสายลับในเครื่อง
📢 แอดแวร์ (Adware)เด้งโฆษณาไม่หยุดใบปลิวยัดใส่มือ

2) ศัพท์อื่นที่ควรรู้

คำศัพท์ความหมาย
Phishing (ฟิชชิง)หลอกด้วยข้อความ/เว็บปลอม ให้กรอกข้อมูลสำคัญ · มาจาก fishing = ตกปลา 🎣
Social Engineeringหลอกที่ "ใจคน" ไม่ใช่ที่เครื่อง · ทำให้กลัว รีบ หรือโลภ
Spam (สแปม)ข้อความ/อีเมลขยะที่ส่งทีละมาก ๆ โดยเราไม่ได้ขอ
Hacker (แฮกเกอร์)ผู้เจาะระบบ · ถ้าทำเพื่อทดสอบหาช่องโหว่โดยได้รับอนุญาต เรียก White hat · ทำผิดกฎหมาย เรียก Black hat
Firewall (ไฟร์วอลล์)กำแพงกั้นการเข้าออกระหว่างเครื่องเรากับอินเทอร์เน็ต
Antivirusโปรแกรมตรวจจับและกำจัดโปรแกรมร้าย
Encryption (การเข้ารหัส)แปลงข้อมูลให้คนอื่นอ่านไม่ออก ถ้าไม่มีกุญแจ · https ใช้วิธีนี้
Backup (สำรองข้อมูล)ทำสำเนาไว้อีกที่ · โดนแรนซัมแวร์ก็ยังมีไฟล์เหลือ
DDoSส่งคำขอจำนวนมหาศาลถล่มเว็บ จนเว็บล่มใช้งานไม่ได้
บัญชีม้าบัญชีธนาคารที่คนร้ายเช่า/ซื้อจากคนอื่น ใช้รับเงินที่โกงมา · ให้คนอื่นเช่าบัญชี เจ้าของบัญชีก็อาจมีความผิดไปด้วย (รายละเอียดในบทกฎหมายดิจิทัล)

5) ศัพท์ที่ควรรู้

คำศัพท์ความหมาย
ISPผู้ให้บริการอินเทอร์เน็ต · บริษัทที่เราจ่ายค่าเน็ตให้
Protocol (โปรโตคอล)กติกาการสื่อสาร ที่ทุกเครื่องตกลงใช้ร่วมกัน
TCP/IPชุดกติกาหลักของอินเทอร์เน็ต · หั่นข้อมูลเป็นชิ้น จ่าหน้าที่อยู่ แล้วประกอบกลับ
HTTP / HTTPSกติกาเปิดหน้าเว็บ · S = Secure ส่งแบบเข้ารหัส (แปลงเป็นรหัสลับ คนอื่นอ่านไม่ออก)
URLที่อยู่เว็บเต็ม ๆ ที่พิมพ์ในช่องด้านบน
IP Address · DNSบ้านเลขที่ของเครื่อง · สมุดเปลี่ยนชื่อเว็บเป็นเลข IP
Download / Uploadดึงข้อมูลลงมาเครื่องเรา · ส่งข้อมูลขึ้นไปจากเครื่องเรา
Bandwidth (แบนด์วิดท์)ปริมาณข้อมูลที่ส่งได้ต่อวินาที · วัดเป็น Mbps (บทหน่วยข้อมูล)
Intranet (อินทราเน็ต)เครือข่ายภายในองค์กร ใช้ได้เฉพาะคนในองค์กร
Server / Clientเครื่องให้บริการ (เช่น เซิร์ฟเวอร์ของ LINE) · เครื่องผู้ใช้บริการ (มือถือเรา)
4G / 5GG = Generation (รุ่น) ของเน็ตมือถือ · เลขยิ่งมาก ยิ่งใหม่ ยิ่งเร็ว

📏 หน่วยข้อมูล · ทำไมมือถือถึงเต็ม?

🌱 ชั้นเมล็ด · รู้แค่นี้ก็เข้าใจ

เวลามือถือขึ้นว่า "พื้นที่เต็ม" 😵 หรือเห็นคำว่า MB GB ตามแพ็กเน็ต — นั่นคือ หน่วยวัดขนาดข้อมูล เหมือน "กรัม กิโลกรัม" ที่ใช้ชั่งของ · เริ่มจากหน้าจอที่เราเคยเห็นกันก่อน

1 👀 หน้าจอที่เห็นในมือถือ

นี่คือหน้า ตั้งค่า › พื้นที่จัดเก็บ ของมือถือ · แตะวงกลมตัวเลข (หรือแตะแถบสี) ดูว่าแต่ละอย่างกินที่ไปเท่าไร 👆

👆 แตะวงกลมตัวเลข ดูว่าข้อมูลแต่ละชนิดใหญ่แค่ไหน
👀 สังเกตไหม: ไฟล์ทีละชิ้นนับเป็น MB (รูป 3 MB · เพลง 4 MB) แต่ทั้งเครื่องนับเป็น GB (128 GB) — เพราะ GB ใหญ่กว่า MB ตั้ง 1,024 เท่า
2 🔧 เปิดดูข้างในไฟล์

รูป เพลง แชท ทุกอย่างในเครื่อง ข้างในเป็นแค่ สวิตช์ไฟ เปิด–ปิด เรียงกันยาว ๆ · เปิด = 1 · ปิด = 0 · ลองแตะหลอดไฟดู 👆

💡 ไฟ 1 ดวง = 1 บิต (bit) · ไฟ 8 ดวง รวมกัน = 1 ไบต์ (Byte) = ตัวอักษรอังกฤษ 1 ตัว
รูป 1 ใบ (3 MB) จึงเป็นไฟเรียงกันราว 25 ล้านดวง 😮
3 🗺️ ภาพรวม: บันไดหน่วยข้อมูล

จากหลอดไฟดวงเดียว รวมกันเป็นก้อนใหญ่ขึ้นทีละขั้น · ยิ่งลงล่าง ยิ่งใหญ่ ⬇️

2) ซื้อมือถือ 128 GB ทำไมบางเครื่องโชว์แค่ราว 119 GB?

🏭
ผู้ผลิตนับ1 GB = 1,000,000,000 ไบต์
(นับแบบเลขกลม ๆ)
📱
ตัวเครื่องนับ1 GB = 1,024 × 1,024 × 1,024
= 1,073,741,824 ไบต์
👉 128,000 ล้านไบต์ ÷ 1,073 ล้าน ≈ 119 GB · พื้นที่ไม่ได้หาย แค่นับคนละแบบ (ระบบปฏิบัติการก็กินที่ไปอีกส่วนหนึ่ง)

3) b ตัวเล็ก กับ B ตัวใหญ่ ไม่เหมือนกัน

📶
b เล็ก = บิตใช้กับ ความเร็วเน็ต
เช่น เน็ตบ้าน 100 Mbps
📁
B ใหญ่ = ไบต์ใช้กับ ขนาดไฟล์ / ความจุ
เช่น รูป 3 MB · มือถือ 128 GB
🧮 เน็ต 100 Mbps ÷ 8 = โหลดได้ราว 12.5 MB ต่อวินาที · หนัง 2 GB (2,048 MB) จึงใช้เวลาราว 3 นาที

4) ของจริงจุได้เท่าไร

ของขนาดโดยประมาณ
💬 ข้อความแชท 1 ข้อความไม่กี่สิบไบต์
📷 รูปจากกล้องมือถือ2–5 MB
🎵 เพลง MP33–5 MB
🎬 คลิป 1 นาที (Full HD)ราว 100 MB
🎞️ หนัง 1 เรื่อง1–4 GB
💿 แผ่นซีดี (CD)ราว 700 MB
📀 แผ่นดีวีดี (DVD) ชั้นเดียวราว 4.7 GB
🔑 แฟลชไดรฟ์16–256 GB
🗄️ ฮาร์ดดิสก์คอมพิวเตอร์หลายร้อย GB ถึงหลาย TB

🌳 ชั้นต้นไม้ใหญ่ · เจาะลึก

1) หลอดไฟ 8 ดวง อ่านเป็นตัวเลขอย่างไร (เลขฐานสอง)

หลอดแต่ละดวงมี "ค่าประจำ" ไม่เท่ากัน · ดวงไหนเปิด ก็เอาค่าของดวงนั้นมาบวกกัน

👉 ตัว A = 01000001 = 64 + 1 = 65 · ไฟ 8 ดวงทำได้ทั้งหมด 256 แบบ (เลข 0 ถึง 255) · ลองเลื่อนขึ้นไปกดหลอดไฟในชั้นเมล็ดดูได้

2) ตัวอักษรเก็บในเครื่องอย่างไร (รหัสอักขระ)

รหัสเก็บอะไรใช้กี่ไบต์ต่อตัว
ASCII (แอสกี)อักษรอังกฤษ ตัวเลข เครื่องหมาย1 ไบต์
TIS-620 (มอก. 620)อักษรไทย มาตรฐานของไทย1 ไบต์
Unicode (ยูนิโค้ด) แบบ UTF-8ทุกภาษาทั่วโลก + อีโมจิอังกฤษ 1 · ไทย 3 ไบต์

3) หน่วยที่ใหญ่กว่า TB และหน่วยย่อยอื่น ๆ

หน่วยเท่ากับ

📝 เรียงครบทั้งบันได (เล็ก → ใหญ่): bit → Nibble → Byte → KB → MB → GB → TB → PB → EB → ZB → YB
บางตำราเขียน KiB MiB GiB เพื่อบอกชัด ๆ ว่านับแบบ 1,024
